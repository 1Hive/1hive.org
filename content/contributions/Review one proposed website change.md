**Candidate idea · Review · First session: 45–90 minutes**

## Why this is useful

The website foundation is itself reviewable work. [PR #1, “Add agent participation and proposal foundation,”](https://github.com/1Hive/1hive.org/pull/1) asks for review of participation language, proposal scope, published documents, and visible navigation. A precise review can help its author finish the work without creating another proposal or duplicating the implementation.

## Scope and sources

First read the latest PR description, diff, discussion, and checks. Choose **one review lens**. For a non-code contribution, compare the language in [[Participate with your agent]] and [[Improvement proposals]] with the repository's authorization and governance boundaries. For a technical review, inspect whether the raw-document allowlist publishes only intended files.

Return a private review note with the commit reviewed, one or more specific observations, source locations, and suggested wording or checks. Separate a blocking defect from a question or optional improvement. A clean review with its coverage stated is also useful.

**Evidence basis:** [PR #1](https://github.com/1Hive/1hive.org/pull/1) was open and draft with head `654576bdb2705d3c3de77796e1707150c43df400` when checked on 10 November 2026. The author already owns that change. Recheck its status before using this brief; a completed PR is not an open task.

## Done when

- The note identifies the latest commit you actually reviewed and the narrow review scope.
- Findings cite a file, section, or line and explain a concrete reader or maintainer impact.
- You distinguish what you verified from assumptions and checks you did not run.
- Suggested changes stay within the PR's purpose and do not turn a repository draft into DAO policy or a funding commitment.

## Coordinate and stop

Read prior reviews to avoid repeating resolved points. If PR #1 has closed or the chosen concern is already addressed, select a different relevant open change or stop with that finding. Do not request formal reviewers, submit an approval, post comments, merge, or deploy without authorization. This candidate does not promise recognition or payment.

## Copy a starting prompt

```text
Read https://1hive.org/AGENTS.md, then recheck
https://github.com/1Hive/1hive.org/pull/1 and its latest discussion.
If still relevant, review only whether its participation and
proposal language preserves human authorization and clearly
separates repository review from governance and funding decisions.
Return a private note with the exact commit, source locations,
concrete findings, and checks not performed. Do not repeat resolved
comments. Do not submit a review, post, approve, merge, or deploy.
```
