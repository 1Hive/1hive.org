**Candidate idea · Research · First session: 45–90 minutes**

## Why this is useful

[[Navigating core community infrastructure]] deliberately describes its links as a reference map, not a live status feed. A small, reproducible check helps readers distinguish a documented destination from a verified current service. It also gives maintainers evidence for a focused correction.

## Scope and sources

Choose **one entry**, such as the [Celeste documentation](https://1hive.gitbook.io/celeste) or [documented Celeste deployment](https://celeste.1hive.org/#/dashboard), from the infrastructure map. Read the destination and compare its visible identity and purpose with the wiki description. Record redirects, source dates, access restrictions, and the exact URL checked.

Return a short evidence note: wiki claim, source observed, checked time in UTC, supported conclusion, remaining uncertainty, and a proposed correction only if needed. A page loading successfully establishes reachability, not working transactions, adequate funds, or an active reward program.

**Evidence basis:** The [reference-map disclaimer and Celeste section at commit 654576b](https://github.com/1Hive/1hive.org/blob/654576bdb2705d3c3de77796e1707150c43df400/content/Navigating%20core%20community%20infrastructure.md), inspected 10 November 2026. This brief does not claim those external destinations were live-verified.

## Done when

- The evidence concerns one named entry and includes the original and final destination if redirected.
- Every conclusion can be traced to a visible source, with a checked date and access limitations.
- You distinguish “reachable,” “documented purpose,” and “current operation not verified.”
- You return a targeted correction or a useful “no correction supported” note. Neither requires testing a financial action.

## Coordinate and stop

Check recent maintenance work for the same destination first. Reuse an existing source record if one exists. Stop before sign-in, wallet connection, signing, voting, or spending. A blocked page is an access limitation, not proof that the service is inactive. Do not replace a destination with an unofficial lookalike. This candidate has no assigned owner or promised reward.

## Copy a starting prompt

```text
Read https://1hive.org/AGENTS.md and check existing maintenance
work. Verify only the Celeste documentation reference in the
1Hive infrastructure map using public, read-only sources.
Return the wiki claim, exact URL, any redirect, visible evidence,
UTC check time, and what remains unverified. Draft a correction
only if the evidence supports one. Do not infer service health
or funding from a loading page. Keep the result private and
stop before login, wallet connection, publication, or transactions.
```
